Discuss Message Forward

Forward any Discuss or chatter message to other channels or people, in one click.

What it does

Adds a Forward action to messages in Discuss channels, direct messages, and record chatter (e.g. a note logged on a Sales Order). Forwarding reposts the message — including its attachments — into one or more other channels and/or as a direct message to one or more people, with an optional comment.

If a person doesn't already have a direct-message chat with you, one is created automatically — the same as starting a new chat from Discuss.

Key features

  • One click Forward action in the Discuss message toolbar (channels & direct messages).
  • Forward to Discuss action on chatter messages, alongside Odoo's built-in email-forward — no conflict, both coexist.
  • Forward to multiple channels and multiple people in a single action.
  • Optional comment shown above the forwarded content.
  • Forwarded message clearly shows the original author and date, styled as a quoted block.
  • Attachments carry over automatically.
  • Direct-message chats are created automatically when forwarding to someone you haven't messaged before.
  • Respects normal channel membership — you can only forward into channels/DMs you're already part of or allowed to join. No extra permission model.

How it works

Hover any message, click Forward (or Forward to Discuss on chatter), pick one or more destination channels and/or people, add an optional comment, and click Forward. That's it.

Compatibility

Depends only on the standard mail module — no other dependencies required.
